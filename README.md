# Inventory Management System

## Project Overview
Inventory Management System is a console-based application developed using Python 3. It helps users manage products, quantities, prices, and stock information efficiently.

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

   ```bash
   python inventory_management.py
   ```

6. Low Stock Report
7. Search Item
8. Exit

## Stock Value Calculation
**Total Stock Value = Quantity × Price**

## Low Stock Criteria
Items having a quantity less than 5 are considered low-stock items.

## Data Storage
Inventory data is stored temporarily using Python lists and dictionaries. Data is not permanent after the program exits.
